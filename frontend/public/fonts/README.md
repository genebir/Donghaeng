# Fonts

자가호스팅 폰트. 모두 SIL Open Font License 1.1 (OFL).

| 파일 | 폰트 | 용도 | 출처 |
|---|---|---|---|
| `PretendardVariable.woff2` | Pretendard Variable | 한국어 본문 | <https://github.com/orioncactus/pretendard> |
| `InterVariable.woff2` | Inter Variable | 영문 본문 | <https://github.com/rsms/inter> |
| `InterVariable-Italic.woff2` | Inter Variable Italic | 영문 본문 (이탤릭) | 같음 |
| `Fraunces-Variable.ttf` | Fraunces Variable | 영문 디스플레이 | <https://github.com/google/fonts/tree/main/ofl/fraunces> |

**Gowun Batang (한국어 디스플레이)** 은 TTF 파일이 16 MB라서 저장소에 두지 않고
`next/font/google`로 빌드 타임에 자동 자가호스팅합니다. 결과물은 동일하게 `/_next/static/`에서 서빙.

## 라이선스

각 폰트의 OFL 라이선스는 위 출처 저장소에 동봉돼 있습니다.
공개 배포 시 폰트 패키지 별도 동봉 또는 footer에 출처 표기 필요.
