# 브랜드 자산 / Brand Assets

이 폴더는 우리들교회 CI와 동행 브랜드 자산을 보관합니다.
**모든 자산은 직접 수정하지 말 것.** 변경이 필요하면 별도 파일로 추가 후 `DESIGN.md` 갱신.

---

## 파일

| 파일 | 용도 | 비고 |
|---|---|---|
| `woori-ci-original.png` | 우리들교회 공식 CI (원본 PNG) | 임시. SVG 발급받으면 교체. |
| `woori-ci-on-dark.svg` | midnight 배경용 (회색 픽셀 + 빨간 십자가) | **대기 중 — 교회 측에서 SVG 받기** |
| `woori-ci-on-light.svg` | paper 배경용 (잉크 픽셀 + 빨간 십자가) | **대기 중 — light 환경 매핑 필요** |
| `donghaeng-wordmark.svg` | 동행 워드마크 | Gowun Batang Bold 기반, 자체 제작 |

---

## CI 사용 규칙 (요약, 자세한 건 `docs/DESIGN.md`)

1. **재제작 금지** — 항상 공식 자산 사용.
2. **최소 크기** — 헤더 24px, 데스크탑 32px (높이).
3. **여백** — 로고 높이의 50% 이상.
4. **변형 금지** — 색 변경, 회전, 비율 왜곡, 효과 추가 X.
5. **락업** — "우리들교회 CI │ 동행" 세로 구분선 패턴만 사용.
