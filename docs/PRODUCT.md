# PRODUCT.md — 제품 스펙

## 누가 쓰나 (Personas)

### 교회 직분 (Organization 레벨, 표시용)
우리들교회 기준: **마을장 → 목자 → 부목자 → 목원**.
- 마을장(VILLAGE_HEAD): 한 마을(셀공동체) 전체 책임자.
- 목자(SHEPHERD): 목장 책임자.
- 부목자(VICE_SHEPHERD): 목자 보조.
- 목원(SHEEP): 일반 성도.

> 이 직분은 **표시 / 필터용**이며, 시스템 권한은 별도(`OWNER` / `ADMIN` / `MEMBER`)로 관리.
> 다른 교회는 organization 설정에서 직분 옵션을 커스터마이즈 가능하도록 (Phase 4).

### 아웃리치 팀 역할 (Team 레벨, 단순화)
**팀장(LEADER) / 팀원(MEMBER)** — 두 가지뿐.
파트(부서)는 별도 필드: `MEDIA` / `WORSHIP` / `TEACHER` / `FINANCE` (회계) / `MEDICAL` / `GENERAL`.

### 페르소나

| 페르소나 | 시스템 권한 | 주요 니즈 |
|---|---|---|
| **조직 관리자** (보통 마을장 / 부목사) | ORG_ADMIN | 여러 팀 한눈에, 진행상황 추적 |
| **팀장** | TEAM_LEADER | 팀 운영 전반, 의사결정, **본인 카드로 사고 영수증 올리기** |
| **회계 담당 팀원** | TEAM_MEMBER + part=FINANCE | **영수증 검토, 정산 처리, 회계 보고서 작성** |
| **파트장** (미디어 등) | TEAM_MEMBER + is_part_lead=true | 파트별 준비, 자료 공유 |
| **팀원 (목원)** | TEAM_MEMBER | 본인 일정/준비물 확인, 사진 업로드, 본인 지출 등록 |
| **본진 성도** | (인증 없음) | 매일 업데이트 / 기도제목 확인 |
| **현지 협력자** | (인증 없음) | QR로 간증/기도제목 남기기 |

## 핵심 기능 (도메인별)

### 1. Trip & Team Management (트립/팀 관리)

**기능**
- 연도별 아웃리치(Outreach) 생성 (예: "2026 여름 단기선교")
- 한 아웃리치 안에 여러 팀(Team) 생성 (예: "우도교회팀", "포항 OO교회팀")
- 각 팀에 방문지(Destination) 정보 연결: 교회명, 주소, 협력 목사님 연락처, 특이사항
- 작년 데이터 복제로 새 트립 시작 가능 ("2025 → 2026 복제")

**유저 스토리**
- 디렉터로서 새 해의 아웃리치를 만들고 팀 5개를 등록한다.
- 팀장으로서 작년 우리팀 데이터를 복제해서 빠르게 시작한다.

### 2. Member & Roles (멤버/역할 관리)

**기능**
- 팀원 초대 (이메일 / 카카오 / 초대 링크)
- 두 단계 역할:
  - 조직 직분 (`church_position`): 마을장 / 목자 / 부목자 / 목원 — **표시용**
  - 팀 역할 (`role`): 팀장(LEADER) / 팀원(MEMBER)
  - 파트 (`part`): MEDIA / WORSHIP / TEACHER / **FINANCE** / MEDICAL / GENERAL
  - 파트 책임자 (`is_part_lead`): 해당 파트의 리드 여부
- 멤버 정보:
  - 기본: 이름, 연락처, 생년월일
  - 응급: 보호자 연락처, 알레르기, 복용약, 혈액형
  - 옷 사이즈, 식이제한 (채식/할랄 등)
  - **계좌정보**: 은행명 / 계좌번호 / 예금주 (정산 송금용)
- 권한 (RBAC):
  - 팀장: 팀 전체 편집, 멤버 응급정보 조회, 지출 승인
  - 회계 파트(part=FINANCE): 지출 검토 / 승인 / 정산 처리
  - 팀원: 읽기 + 본인 정보 + 미디어 업로드 + **본인 지출 등록**
- 비상연락망 자동 생성 (PDF 다운로드)

**유저 스토리**
- 팀원으로서 초대 링크를 받아 가입하고, 응급정보와 **계좌정보**를 입력한다.
- 팀장으로서 비상연락망을 PDF로 받아 보호자들에게 배포한다.

- **권한**: 비공개 / 팀 내 공개 / 본진 공개 / 전체 공개 단계 설정
- **워크플로우**: 누가 편집중인지 표시, 완료 시 본진 페이지에 게시

**스토리지 정책**

### 8. Accounting (회계 / 지출 / 정산) ⭐ 핵심

> **현실의 페인포인트**: 팀장들이 본인 카드/현금으로 30~100건씩 사고, 단톡방에 영수증 사진 흩어지고, 마지막에 회계 담당이 며칠 동안 엑셀로 정리해서 한 명씩 송금. 매년 반복.

이걸 **3단계로 깔끔하게 처리**한다:
**(1) 지출 등록** → **(2) 검토/승인** → **(3) 인별 정산 송금**.

#### 8-1. 지출 등록 (Expense)

**팀장이든 누구든 본인이 결제한 항목을 30초 안에 올린다.**

- 모바일 우선 UX:
  1. "지출 추가" 탭 → 카메라 즉시 실행
  2. 영수증 촬영 → **OCR 자동 추출** (총액, 가게명, 일시)
  3. 카테고리만 선택 (TRANSPORT / LODGING / MEAL / MINISTRY / GIFT / SUPPLIES / MEDICAL / MISC)
  4. 한 줄 설명 ("VBS 둘째날 간식")
  5. 저장
- 자동 추출이 틀리면 한 탭으로 수정.
- **결제수단**: 개인카드 / 개인현금 / 교회법인카드 / 기타.
- 준비물 항목과 연결 가능 (`checklist_item_id`) — 체크리스트의 "30명분 모기약 사기"가 자동 완료 처리됨.
- 외화 지원 (해외 단기선교용): 통화 + 환율 메모.

**OCR 옵션**
- 1순위: 네이버 클로바 OCR (한국 영수증 인식률 최상, 영수증 특화 API 있음)
- 2순위: Google Cloud Vision (해외 영수증)
- 3순위: 수동 입력만 (Phase 2 초기)

#### 8-2. 검토 / 승인 (Approval)

**회계 담당자(part=FINANCE)나 팀장이 한 곳에서 모든 영수증 검토.**

- 필터: 상태(pending/approved/rejected) / 카테고리 / 결제자 / 기간
- 한 화면에서 영수증 사진 + 정보 + 카테고리 빠르게 확인
- 액션:
  - **승인**: 한 건 또는 일괄 (예: "이번 주 식비 18건 다 승인")
  - **반려**: 사유 입력 (영수증 흐릿함, 카테고리 잘못됨 등) → 등록자에게 알림
  - **수정**: 승인 전이면 카테고리/금액 수정 가능
- 진행률 위젯:
  - "총 등록 87건 / 승인 64건 / 대기 18건 / 반려 5건"
  - 카테고리별 사용액 vs 예산

#### 8-3. 정산 / 송금 (Reimbursement)

**정산 마감 시점에 한 번에 처리. 인별 송금 금액 자동 계산.**

- "정산 시작" 버튼 → 승인된 expense를 **결제자별로 자동 그룹핑**
- 각 사람마다 정산 묶음(reimbursement) 생성:
  ```
  ┌─────────────────────────────────────────┐
  │ 김OO 팀장                              │
  │ 국민은행 12345-67-890123 / 김OO        │
  │                                        │
  │ 식비       12건  ₩342,500              │
  │ 사역도구    8건  ₩198,000              │
  │ 교통비      3건  ₩45,000               │
  │ ─────────────────────────              │
  │ 합계       23건  ₩585,500              │
  │                                        │
  │ [ 송금 정보 복사 ]  [ 송금 완료 처리 ]   │
  └─────────────────────────────────────────┘
  ```
- "송금 정보 복사" → `국민 12345-67-890123 김OO ₩585,500` 클립보드 (뱅킹앱에 바로 붙여넣기)
- "송금 완료 처리" → 묶인 expense 모두 `reimbursed`로 일괄 변경
- 실수 방지:
  - draft 단계에선 항목 변경 가능
  - confirmed 단계에선 잠금 (송금 직전)
  - completed 후 변경하려면 정산 묶음을 다시 풀어야 함 (감사 로그 남김)

#### 8-4. 예산 (Budget)

- 카테고리별 예산 계획 (트립 시작 전 입력)
- 실시간 vs 실집행:
  - 막대그래프 (계획 / 승인 / 미승인 누적)
  - 초과 카테고리 빨간 표시
- 카테고리: TRANSPORT / LODGING / MEAL / MINISTRY / GIFT / SUPPLIES / MEDICAL / MISC

#### 8-5. 보고 / 출력 (Reports)

**교회 회계팀에 제출할 자료를 한 번에 뽑는다.**

- **회계 보고 Excel**:
  - 시트 1: 전체 지출 리스트 (일자, 결제자, 카테고리, 금액, 가게, 영수증 링크)
  - 시트 2: 카테고리별 합계
  - 시트 3: 인별 정산 내역
- **정산 PDF** (한 사람당 한 장):
  - 묶인 영수증 사진 + 합계 + 송금 정보
- **영수증 일괄 ZIP 다운로드** (원본 사진 + 메타 CSV)

#### 8-6. 권한

| 액션 | LEADER | FINANCE 파트 | 일반 팀원 |
|---|---|---|---|
| 본인 지출 등록 | ✅ | ✅ | ✅ |
| 모든 지출 조회 | ✅ | ✅ | 본인 것만 |
| 지출 승인/반려 | ✅ | ✅ | ❌ |
| 정산 묶음 생성/확정 | ✅ | ✅ | ❌ |
| 송금 완료 처리 | ✅ | ✅ | ❌ |
| 계좌정보 조회 | ✅ (정산 시) | ✅ (정산 시) | 본인 것만 |
| 보고서 다운로드 | ✅ | ✅ | ❌ |

> 모든 승인 / 정산 / 송금완료 액션은 audit_log 기록.

#### 8-7. 유저 스토리

- 팀장으로서 마트에서 간식 ₩45,000 사고 영수증 촬영 → 카테고리 선택 → 30초 만에 등록 완료.
- 회계 담당으로서 매일 저녁 그날 올라온 지출 30건 일괄 승인.
- 회계 담당으로서 트립 종료 후 "정산 시작" 누르고, 7명에게 각자의 송금정보 복사하며 차례대로 송금.
- 팀장으로서 송금 완료 알림을 받고 "정산 완료" 확인.
- 회계로서 교회 사무실에 제출할 Excel + ZIP을 한 번에 다운받는다.

## 비기능 요구사항

- **모바일 우선**: 현장에서 폰으로 다 처리 가능해야 함. 태블릿/데스크탑은 보조.
- **오프라인 내성**: 미디어 업로드는 네트워크 약할 때 큐잉 후 재시도.
- **속도**: 사진 100장 업로드가 5G에서 2분 내.
- **다국어**: 한국어 우선. QR 폼만 영어/일본어 추가 (Phase 3).
- **접근성**: WCAG AA 준수. 키보드 네비게이션, alt 텍스트.
- **개인정보**: 멤버 응급정보는 팀장/부팀장만 조회 가능. 감사 로그 남김.
